API REST

Connectez un site web ou la comptabilité aux données du stock

Base : {{ request.scheme }}://{{ request.get_host }}/stock/api/

Authentification : session (navigateur) ou jeton (intégrations).

Obtenir un jeton : POST /stock/api/token/ avec username et password, puis envoyez l'en-tête Authorization: Token <votre_jeton>.

Exemple
# 1) Obtenir un jeton
curl -X POST {{ request.scheme }}://{{ request.get_host }}/stock/api/token/ \
     -d "username=VOTRE_USER&password=VOTRE_MDP"

# 2) Lister les articles (stock, prix, valeur)
curl {{ request.scheme }}://{{ request.get_host }}/stock/api/articles/ \
     -H "Authorization: Token VOTRE_JETON"

# 3) Enregistrer une sortie de stock
curl -X POST {{ request.scheme }}://{{ request.get_host }}/stock/api/mouvements/ \
     -H "Authorization: Token VOTRE_JETON" \
     -d "article=1&depot=1&type_mouvement=sortie&quantite=2"
